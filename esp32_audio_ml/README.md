# ESP32-S3 TinyML Voice Activator & Audio Node (Arduino IDE)

This directory contains the complete edge AI voice activator and audio streaming pipeline rewritten strictly for the **standard Arduino IDE**.

---

## Folder Structure

```text
esp32_audio_ml/
├── esp32_audio_ml.ino    # Main Arduino sketch (FreeRTOS audio, inference, & WebSocket tasks)
├── model.h               # Placeholder C-byte array for your converted TFLite TinyML model
├── server.py             # Python WebSocket audio server (saves WAV, sends "stop" command)
└── README.md             # This quickstart guide
```

---

## 1. Hardware Connections (INMP441 Microphone -> ESP32-S3)

> [!CAUTION]
> **VOLTAGE WARNING**: Connect INMP441 **VDD to 3.3V** (`3V3` pin on ESP32-S3). Connecting VDD to 5V will permanently burn out the microphone chip!

| INMP441 Pin | ESP32-S3 Pin | Function | Notes |
| :--- | :--- | :--- | :--- |
| **VDD** | **3V3** | 3.3V Power | **Do NOT use 5V / VIN** |
| **GND** | **GND** | Ground | Common ground |
| **SD** | **GPIO 4** | Serial Data (DOUT) | Audio data from mic to ESP32-S3 |
| **WS** | **GPIO 5** | Word Select (LRCLK) | Frame clock (Left / Right select) |
| **SCK** | **GPIO 6** | Serial Clock (BCLK) | Bit clock generated by ESP32-S3 |
| **L/R** | **GND** | Channel Select | **Must connect to GND** (selects Left mono channel) |

## 2. Arduino IDE Setup

### Step 1: Install ESP32 Board Support
1. In Arduino IDE, open **File $\rightarrow$ Preferences**.
2. In **Additional boards manager URLs**, add:
   ```text
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. Open **Tools $\rightarrow$ Board $\rightarrow$ Boards Manager**, search for **`esp32`** by Espressif Systems, and click **Install**.

### Step 2: Install Required Libraries
1. Open **Sketch $\rightarrow$ Include Library $\rightarrow$ Manage Libraries** (or `Ctrl + Shift + I`).
2. Search for **`WebSockets`** by **Markus Sattler**.
3. Click **Install**.

### Step 3: Board Settings in Arduino IDE
Under the **Tools** menu, select:
- **Board**: `ESP32S3 Dev Module` (or your specific ESP32-S3 variant)
- **USB CDC On Boot**: `Enabled` (so Serial Monitor works over native USB)
- **Upload Speed**: `921600`
- **Flash Size**: `8MB` (or matches your chip)
- **Port**: Select your ESP32-S3 COM Port

## 3. Configuration in `esp32_audio_ml.ino`

Open `esp32_audio_ml.ino` and update your network settings:

```cpp
const char* WIFI_SSID         = "YOUR_WIFI_NAME";       // 2.4 GHz Wi-Fi
const char* WIFI_PASS         = "YOUR_WIFI_PASSWORD";

const char* WS_SERVER_IP      = "192.168.1.100";        // Your PC's IPv4 address
const uint16_t WS_SERVER_PORT = 8000;
const char* WS_SERVER_PATH    = "/ws/esp32";
```

## 4. Running the Python Server

1. Open a terminal / command prompt in this directory:
   ```powershell
   cd esp32_audio_ml
   ```
2. Install the lightweight WebSocket library:
   ```powershell
   pip install websockets
   ```
3. Run the server:
   ```powershell
   python server.py
   ```
   *(The server will print your PC's local IP address and listen for connections)*.

### Server Controls:
- **Auto-Stop**: By default, recording automatically stops after **5.0 seconds** of audio, sends the `"stop"` command to the ESP32, and saves the WAV file.
- **Manual Stop**: Press **`Enter`** in the server terminal anytime to broadcast the `"stop"` command to all active nodes.
- **Custom Auto-Stop Duration**: Run `python server.py --auto-stop 10` (or `0` to disable auto-stop and stop only manually).

## 5. Testing the End-to-End Pipeline

1. Upload the sketch to your ESP32-S3 from Arduino IDE.
2. Open **Tools $\rightarrow$ Serial Monitor** at **115200 baud**.
3. You will see:
   ```text
   [WIFI] Connected! IP: 192.168.1.52
   [WS] Connecting to WebSocket: ws://192.168.1.100:8000/ws/esp32
   [WS] >>> CONNECTED to ws://192.168.1.100:8000/ws/esp32 <<<
   [MIC STATUS] State: LISTENING | Peak:  1420 | RMS: 185.3 | WS: CONNECTED
   ```
4. **Simulate a Wake-Word Trigger**:
   - Type **`t`** and press **Enter** in the Serial Monitor.
   - The ESP32 switches to `STATE_STREAMING` and streams live audio frames.
   - The Python server terminal shows live VU meters and packet counters:
     ```text
     [AUDIO REC] Duration:  4.2s | Pkts:  131 | RMS: 340.2 | Peak: 2890 [██████░░░░] (Press Enter to STOP)
     ```
   - When the duration limit is reached (or when you press `Enter` in the server terminal), the server sends the `"stop"` command.
   - The ESP32 logs:
     ```text
     [WS] Received 'STOP' command from server!
     [WS] Halting audio streaming -> Returning to LISTENING
     ```
   - The server saves the audio to `recordings/audio_<timestamp>.wav` (16 kHz, 16-bit Mono).

## 6. How to Deploy Your Own TinyML Model (`model.h`)

When you train your keyword spotting model (e.g. via TensorFlow, Keras, or Edge Impulse):

1. Export your model as an INT8-quantized `.tflite` file (e.g. `wake_word.tflite`).
2. Convert it to a C array:
   ```powershell
   python -c "b=open('wake_word.tflite','rb').read(); open('model.h','w').write(f'#pragma once\nconst unsigned int g_model_len = {len(b)};\nconst unsigned char g_model[] __attribute__((aligned(16))) = {{' + ', '.join(map(hex, b)) + '};\n')"
   ```
   *(Or using `xxd -i wake_word.tflite > model.h`)*.
3. Replace the `g_model[]` placeholder array inside [`model.h`](model.h).
